Official partner platform for HE Paramotores S.L. (Madrid, Spain).

## Features
- 5 engine models
- Parts catalogue with filters
- Configurator (5-step builder)
- Service center booking
- Owner dashboard (serial number lookup)
- Atelier (custom builds)
- Technical library
- Contact form

## Technologies
- Pure HTML/CSS/JS (no dependencies)
- Space Grotesk + Cormorant Garamond + JetBrains Mono
- Cream/Navy/Terra cotta palette
- GitHub Pages deployment
